# גראז׳ סייל — תכולת דירה

עמוד מכירה של תכולת דירה שלמה בנווה שרת, תל אביב: 40 פריטים — מוצרי חשמל, ריהוט, אלקטרוניקה, מערכת בית חכם וצמחים — שנמכרים לקראת מעבר דירה, ברובם במחצית ממחיר החנות.

העמוד נבנה כדי להתלוות לפוסט בפייסבוק ולהודעות בקבוצות וואטסאפ: הפוסט מציג כמה פריטי דגל, והלינק מוביל לרשימה המלאה עם המחירים והתמונות.

## מה יש בעמוד

כל פריט מוצג עם תמונה, שם, תיאור קצר, מחיר המכירה ולצידו מחיר החנות ואחוז ההנחה. לחיצה על הכרטיס פותחת חלון עם תיאור מלא — מצב הפריט, מה כלול בו, ולמוצרים מורכבים כמו ארונות PAX וערכת התאורה גם פירוט רכיבים ומחיר החנות של כל אחד. לחיצה על התמונה פותחת לייטבוקס עם מעבר בין כל תמונות הפריט.

הרשימה ניתנת לסינון לפי שש קטגוריות ולחיפוש חופשי, והעמוד קיים בשלוש שפות — עברית, רוסית ואנגלית — כולל החלפת כיווניות ופורמט מחירים. פריט שנמכר מקבל תג, פס מחיר שחור וכרטיס מעומעם, ונשאר ברשימה.

## טכנית

עמוד סטטי יחיד, בלי תלויות ובלי שלב בנייה. כל הקוד והעיצוב יושבים ב-`index.html`; הגופן היחיד שנטען מבחוץ הוא Heebo מ-Google Fonts. העיצוב מותאם לנייד ומגיב למצב כהה.

| קובץ | תוכן |
|---|---|
| `index.html` | העמוד כולו — תוכן, עיצוב וקוד. 40 הפריטים בשלוש שפות נמצאים במערך `ITEMS`. |
| `sold.json` | מזהי הפריטים שנמכרו. |
| `images.json` | מיפוי בין מזהה פריט לקבצי התמונות שלו. |
| `img/` | התמונות. `img/og.jpg` היא תמונת התצוגה המקדימה של הלינק ברשתות. |
